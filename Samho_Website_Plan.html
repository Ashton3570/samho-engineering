제작 목표
삼호엔지니어링이 무엇을 제조하고, 어떤 생산 기반을 갖췄으며, 어떻게 상담하면 되는지 명확하게 보여주는 사이트를 만든다.

01 / FIRST IMPRESSION

메인 화면에서 회사의 정체성을 바로 보여주기

산업적인 분위기를 살리되, 방문자가 첫 화면에서 다음 세 가지를 이해할 수 있도록 한다.

  • 무엇을 하는가: 베어링 부품 전문 제조
  • 어떤 기반이 있는가: 1979년부터 이어온 제조 경험, 영주 생산거점
  • 어디로 가면 되는가: 생산 제품 보기 / 제작 문의

감성적인 문구는 큰 제목에 사용하고, 바로 아래 설명에는 TRB·DGBB 케이지, 실드, 레이스웨이를 구체적으로 적는다. 추상적인 문구만 이어지면 회사가 무엇을 하는지 이해하기 어렵다.

첫 화면의 주요 버튼은 ‘생산 제품 보기’와 ‘제작 문의’ 두 개를 중심으로 구성한다.

02 / INFORMATION STRUCTURE

방문자의 질문에 맞춰 페이지 구성하기

한 페이지에 담은 시안은 전체 방향을 검토하기 좋다. 실제 사이트에서는 정보가 충분한 영역부터 상세 페이지로 나누면 관리와 탐색이 편해진다.

페이지담을 내용방문자가 얻어야 하는 답
메인회사 핵심 소개, 주요 제품, 생산 기반, 문의 안내어떤 회사인가?
회사소개연혁, 경영 철학, 회사 개요어떤 경험과 방향을 갖고 있는가?
제품소개제품군, 외경 범위, 용도, 상세 문의내가 찾는 부품을 제조하는가?
생산·품질Site-A/B, 공정, 검사, 인증어떻게 생산하고 관리하는가?
문의연락처, 위치, 제작 상담누구에게 어떤 자료를 보내면 되는가?

메인에는 핵심만, 상세 페이지에는 충분한 정보를 담는다. 내용이 부족한 페이지는 무리하게 분리하지 않고 자료가 확보된 것부터 나눈다.

03 / TRUST & EVIDENCE

근거가 있는 내용을 잘 보여주기

산업 기업 사이트에서는 실제 제품, 생산 현장, 명확한 규격, 품질 관리의 근거가 신뢰를 만든다.

요소표현 아이디어필요한 자료
제조 경험주요 전환점 중심의 간결한 연혁책자 내용으로 시작 가능
생산거점Site-A와 Site-B의 역할을 나란히 소개실제 건물·내부 사진
제품 전문성제품군별 규격과 특징을 통일된 형식으로 정리책자 및 담당자 확인
품질 인증인증명·범위·유효기간을 읽기 쉽게 표시최신 인증 정보
검사 역량검사 항목과 장비를 설명하는 짧은 콘텐츠실제 검사 절차·장비명
고객 관계확인된 거래처를 절제된 텍스트나 로고로 표시공개 가능한 범위 확인

‘최고의 품질’, ‘세계적인 기술력’ 같은 표현을 반복하기보다 실제로 무엇을 확인하고 관리하는지 구체적으로 보여준다.

04 / PRODUCT EXPERIENCE

제품소개를 사이트의 중심으로 만들기

  • 제품군별로 묶기: 케이지 / 실드·커버·캡 / 레이스웨이에서 시작해 개별 제품으로 이동하도록 구성한다.
  • 상세 페이지 형식 통일: 제품명 → 짧은 설명 → 실제 제품 이미지 → 생산 외경 → 적용 구분 → 문의 버튼 순서로 정리한다.
  • 핵심 규격 먼저 표시: 긴 설명보다 외경 범위를 먼저 찾을 수 있게 배치한다.
  • 영문 약어 설명: TRB, DGBB, ACBB를 처음 접하는 방문자를 위해 한국어 설명을 함께 제공한다.
  • 미기재 정보 확인: 책자에 없는 재질·공차·표면처리는 담당자 확인 후 추가한다.
  • 제품별 문의 연결: ‘이 제품 문의’를 누르면 제품명이 문의 양식에 자동으로 들어가게 한다.
  • 규격 중심의 비교: 제품 구분·외경·생산능력을 비교하되, 서로 대체 가능한 제품처럼 보이지 않게 구성한다.
  • 생산능력 기준 명확화: 연간 생산능력과 현재 공급 가능 물량을 구별해 표시한다.
  • 제품 자료 다운로드: 최신 규격서가 준비되면 제품별 다운로드로 연결한다.

현재 정리한 제품 9종 규모에서는 복잡한 검색 기능보다 명확한 분류와 잘 정리된 제품 카드를 우선한다.

05 / IMAGE PLAN

이미지는 필요한 장면 목록부터 정하기

이미지 제작은 별도 요청 시 진행한다. 지금은 필요한 위치와 역할을 정해두고, 회사 책자의 이미지는 사용하지 않는다.

이미지역할구도 아이디어
메인 이미지제조 전문성 전달실제 부품이나 현장을 넓게 보여주고 문구 공간 확보
제품 대표 이미지제품 형태 식별같은 배경·각도·조명으로 촬영
제품 확대 이미지가공 형상과 디테일 전달중요한 부위를 가까이 보여주기
생산동 외관실제 사업장 확인건물과 출입구가 명확한 구도
생산 공정제조 과정 이해작업 대상과 설비의 관계가 보이는 장면
품질 검사관리 과정의 구체성 전달측정 대상과 장비가 함께 보이는 장면

제품 사진의 통일감이 중요하다. 사진마다 배경·크기·조명이 다르면 사이트 전체가 어수선해 보일 수 있다.

실제 제품 형상과 공장 설비를 설명하는 사진은 실제 자료를 사용한다. 연출 이미지는 메인 분위기나 배경에 활용한다. 제품 사진이 준비되기 전에는 텍스트와 규격 중심의 정돈된 구성으로 진행한다.

06 / DESIGN PRINCIPLES

한 가지 디자인 원칙을 끝까지 유지하기

SKF 참고 시안을 발전시키는 경우 다음 방향을 일관되게 적용한다.

  • 화이트·딥네이비 중심, 블루는 강조: 강한 파란색을 모든 영역에 채우기보다 버튼과 핵심 정보에 집중한다.
  • 제목 크기의 체계: 메인 제목, 섹션 제목, 제품명, 설명의 차이를 일정하게 유지한다.
  • 본문 폭 제한: 글이 화면 끝까지 길게 이어지지 않도록 구성한다.
  • 숫자 표현 통일: 면적·수량·규격의 단위와 자릿수 표기를 맞춘다.
  • 카드 스타일 통일: 테두리, 내부 여백, 버튼 위치를 제품마다 동일하게 유지한다.
  • 섹션별 역할 구분: 회사소개는 이야기, 제품은 탐색, 생산·품질은 근거, 문의는 행동에 집중한다.
  • 절제된 움직임: 간단한 등장 효과와 버튼 반응부터 완성한다.
  • 모바일 별도 정리: 긴 제품명, 비교표, 메뉴, 문의 입력이 작은 화면에서도 편한지 확인한다.

우선 다듬을 대상은 첫 화면, 제품 카드, 생산·품질 영역의 통일감이다.

07 / ENQUIRY FLOW

방문자가 실제로 상담을 시작하기 쉽게 만들기

현재 마련한 요청서 작성·복사·저장 기능을 바탕으로 실제 연락 흐름을 완성한다. 먼저 대표 전화, 문의 이메일, 사업장 주소, 담당 부서를 확보한다.

기능기대 효과우선순위
전화·이메일 바로 연결가장 빠르게 실제 상담 가능높음
제품명이 자동 입력되는 문의제품명을 다시 설명하는 번거로움 감소높음
필수 항목을 줄인 문의 양식작성 부담 감소높음
접수 완료·실패 안내전달 여부를 명확하게 확인실제 전송 연결 시 필수
도면 첨부제작 가능 여부 검토에 도움다음 단계
연간 물량·납기 입력양산 상담 구체화다음 단계
문의 유형 선택제품 문의·신규 제작·양산 상담 구분선택

처음부터 입력란을 많이 만들지 않는다. 회사·담당자, 회신 연락처, 문의 내용을 기본으로 두고 규격·수량·도면 정보는 필요한 경우 추가하도록 한다.

요청서 작성·저장과 실제 문의 전송은 다른 기능이다. 실제 전송이 연결되기 전에는 접수가 완료된 것처럼 안내하지 않는다.

08 / LATER PHASES

관리와 자료가 필요한 기능은 순서대로 추가하기

  • 영문 사이트: 해외 고객을 대상으로 사용할 계획이라면 가치가 높다. 한국어 내용을 먼저 확정한 뒤 번역하면 재작업이 줄어든다.
  • 공지·뉴스: 정기적으로 올릴 담당자가 있을 때 추가한다.
  • 자료실: 최신 카탈로그와 규격서가 준비됐을 때 추가한다.
  • 공장 소개 영상: 실제 촬영 자료를 확보한 뒤 검토한다.
  • 제품 3D 회전: 정확한 모델과 충분한 필요성이 있을 때 검토한다.
  • 챗봇: 제품·상담 정보가 정리되고 반복 문의가 쌓인 뒤 검토한다.
  • 회원가입·고객 전용 공간: 실제 고객 업무에 필요한 기능이 생기면 검토한다.

업데이트가 멈춘 뉴스나 내용이 빈 자료실은 완성도를 떨어뜨릴 수 있다. 꾸준히 관리할 수 있는 범위까지 만드는 것도 중요한 디자인 결정이다.

09 / MATERIALS TO COLLECT

업체에서 필요한 자료를 한 번에 받기

  1. 회사 기본 정보: 정식 회사명, 주소, 전화, 이메일, 로고 원본
  2. 제품 정보: 공개할 제품군, 최신 생산규격, 강조할 주력 제품
  3. 생산 정보: 생산동 역할, 공개 가능한 공정·설비 설명
  4. 품질 정보: 최신 인증 내용, 공개 가능한 검사 항목
  5. 이미지: 제품, 공장, 생산, 검사 사진
  6. 영업 방향: 국내·해외 중 주 고객, 주로 받고 싶은 문의
  7. 검토 담당자: 최종 문구와 공개 범위를 확인해 줄 사람

책자의 모든 내용을 홈페이지에 옮기기보다, 고객이 업체를 판단하는 데 필요한 정보부터 선별한다.

10 / EXECUTION PLAN

실행 순서와 사용량 관리

단계작업완료 기준
1대표 시안 확정하나의 디자인을 기준으로 수정
2내용과 메뉴 정리회사·제품·생산·문의의 흐름 확정
3핵심 화면 완성메인과 제품소개를 일관된 모습으로 정리
4실제 자료 반영연락처·사진·확인된 규격 적용
5문의 연결상담이 실제 담당자에게 전달
6PC·모바일 점검잘림·오류·불편한 입력 수정
7최종 검토업체 확인 사항 반영 후 공개

한 단계의 수정 사항을 모아서 한 번에 처리하고, 확정된 부분은 고정한다. 대표 시안만 대상으로 수정하면 여러 시안을 동시에 관리하는 부담을 줄일 수 있다.

  • 첫 묶음: 전달 전 임시 문구·버튼·연락처 영역 정리
  • 두 번째 묶음: PC·모바일의 글자 잘림, 메뉴, 제품 검색, 요청서 기능을 한 번에 점검
  • 세 번째 묶음: 업체 피드백을 모아서 반영

남은 사용량으로 가능한 작업 범위를 정확히 보장할 수는 없다. 불필요한 새 시안, 반복 이미지 생성, 전체 코드 재작성을 줄이고 피드백 수정에 여유를 남긴다.

APPENDIX / DRAFT HANDOFF

미완성 초안을 전달하는 방법

초안은 ‘디자인·내용 검토를 위한 1차 시안’으로 전달한다. 이번에 결정할 것과 다음 단계에서 완성할 것을 구분해 안내한다.

이번에 확인받을 항목

  • 디자인 방향: 색상, 분위기, 글자 크기와 배치
  • 회사 정보: 제품 설명, 연혁, 인증, 생산규격의 정확성
  • 페이지 구성: 강조할 내용과 빼야 할 내용
현재 상태초안에서 처리하는 방법
실제 제품·공장 사진 미확정기존 이미지는 임시 콘셉트임을 전달하고, 부품별 제품 목록은 규격·설명 중심으로 보여준다.
연락처·상담 채널 미정해당 영역을 간결하게 정리하고, 실제 정보가 확정되면 연결한다.
견적 전송 기능 미연결현재 가능한 요청서 작성·복사·저장까지만 명확하게 안내한다.
회사 수치의 최신 여부 확인 필요책자 기준일을 유지하고 담당자에게 수정할 수치를 확인받는다.
부가 기능이 많아 보임회사 소개·제품·생산거점을 먼저 보여주고 상담 도우미는 뒤에 배치한다.

작동하지 않는 버튼, 빈 영역, 실제 제품으로 오해할 만한 이미지를 먼저 정리한다. 사진 확정, 문의 연결, 최종 모바일 점검은 다음 단계로 안내한다.

대표로는 회사 책자 내용이 반영된 SKF 참고 4차 시안을 먼저 전달하는 방향을 제안했다. 1~3차 시안은 예전 내용이 남아 있으므로 필요할 때 디자인 비교용으로 보여준다.

사이트 링크를 외부에 전달할 때에는 수신자의 열람 가능 여부를 먼저 확인한다. 이 문서 생성으로 사이트의 공유 범위가 변경되지는 않는다.

회사 소개를 읽고, 생산 제품을 확인하고, 수정 의견을 줄 수 있는 상태.
