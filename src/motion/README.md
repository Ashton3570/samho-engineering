# Eight opening directions

Build with `python3 src/motion/build.py` from the review project root.

- 01–04 retain the centered original logo and change its formation.
- 05–08 use blue panels, photographic shutters, letter choreography, and a photographic circle.
- Each animation lasts 4.5 seconds; all six earlier typography options are available.
- The exact original SVG paths and selected blue product photo are reused.
- No production website assets are changed. This project is the separate owner-private review site.
- SVG animation is deterministic and seekable. Poster scenes remain still; animation runs only when requested, and stops when the document becomes hidden.
- Offline HTML embeds the original assets, font subsets, licenses, and JavaScript.

QA: visually inspected eight directions on desktop, checked portrait layouts at 390×844, checked widest caption choices for overflow, and checked playback/seek/replay and hero transition.
