# 갤러리 히어로 전환

사용자 요청: 전체 개선점은 보고서로만 정리하고, 오프닝 전환만 수정한 뒤 배포.

- 4.5초 총 길이와 2.75초 로고 형성 완료 시점 유지.
- 흰 레이어가 3.3~4.5초에 걸쳐 천천히 옅어지고 밝은 블루 제품 사진으로 연결.
- 사진은 1.8% 확대 상태에서 원래 크기로 정착. 문구 카드는 3.75~4.5초에 투명도와 12px 이동으로 등장.
- 오프닝 동안 스크롤 잠금으로 생길 수 있는 폭 변화를 막도록 스크롤바 공간 유지.
- 건너뛰기/완료 시 전환 변수 제거 및 기존 상호작용 복원.
- 3.5초, 4.1초, 4.5초 장면 비교. 전환 전후 히어로 너비 1425px 동일(1440px 검수 화면).
- 전체 점검 보고서는 프로젝트 상위 output/site-audit에 저장하며 웹 공개 폴더에 포함하지 않음.
