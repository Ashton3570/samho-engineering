# 제공 자료를 활용한 홈페이지 보완

2026-09-22 사용자 요청. 로컬 dist에만 반영하며 배포하지 않음.

## 검토한 자료

- 삼호엔지니어링 브로슈어.pdf: 18 PDF 페이지. 회사·제품 텍스트와 이미지 대응 확인.
- 유스튜디오: 최상위 JPG 105개 검토. 전경스케치 하위 폴더와 ZIP의 중복은 다시 사용하지 않음.
- 베어링 AI 이미지: 이미지 17개 검토. 로고는 기존 승인본과 달라 교체하지 않음.
- 기존 Samho.pdf: 제품 수치와 출처 확인. 10쪽 DGBB 외경 40–300 mm 재확인.

## 반영

- 7개 제품에 대표 이미지, 5개 제품에 추가 각도 이미지. 새 탭 확대 보기.
- 제품 목록 및 메인 하단 제품군에 썸네일. 기존 히어로 마크업 유지.
- 생산·품질: 코일 소재 보관, 케이지 성형, 케이지 확인 작업, 측정 장비, 검사실 사진과 설명.
- 회사소개: AI 케이지 콘셉트와 제조·제품군 소개. AI 생성 이미지 명시.
- 자료실: 제품 요약 CSV, 상담 체크리스트 링크, 영문 회사소개, FAQ 4개.
- 4.5초 opening-v3는 같은 타이밍으로 유지하고 배경 홈페이지 내용만 최신 빌드 반영.

## 수치·누락·제외

- 새 브로슈어 5·10쪽 DGBB 외경 `400–300 mm`는 오류. 사용자가 이번 대화에서 `40–300 mm가 맞음`으로 확인함. 웹과 CSV는 40–300 mm 유지.
- 인원·시설·생산능력은 기존 소개서 2025.10.01 기준을 유지. 현재 재고·가용 생산량으로 해석하지 않음.
- 기존 확정 경영철학 전문은 변경하지 않음.
- 실제 사진/규격이 확인되지 않은 황동 케이지와 프레스 성형 레이스웨이의 이미지·미확인 수치는 빈 상태 유지.
- 전화·이메일·상세 주소·인증 유효기간·설비 모델·정밀도·재질·공차를 추정하지 않음.
- 새 PDF에는 반복 편집 시안, 매출/고객별 구성 자료, 마지막 타사 웹사이트 참고 화면이 포함되어 있음. 원본 전체를 완성 카탈로그로 다운로드 제공하거나 타사 화면을 회사 사실로 재사용하지 않음.

## 유지보수

- `src/materials.json`: 원본 파일·alt·웹 이미지 크기 대응표.
- `scripts/prepare_reference_assets.py`: 원본을 그대로 보존하며 WebP 480/960/1440 파생본 생성.
- `reference_content.py`: 제품 이미지·생산 현장·자료실·CSV 구성.
- `build.py`: 17개 페이지 생성. `scripts/build_indigo_opening.py`: 4.5초 오프닝 미리보기 재생성.
- 이미지 크기 속성, srcset, 지연 로딩 사용. 대표 제품 이미지 1장은 즉시 로딩.

## 검수

- 17개 페이지와 3개 오프닝 미리보기의 링크·앵커·확정 경영철학·빈 규격 유지 검사 통과.
