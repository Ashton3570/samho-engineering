# 오프닝 시안 01 — 금속의 윤곽

별도 경로 `/previews/opening-v1/`에서만 실행됩니다. 현재 홈페이지의 내용과 히어로, 기존 방문자의 진입 동작은 바꾸지 않았습니다. 공개 시안 경로이며 검색 제외 메타 태그를 적용했습니다.

## 구성

- 0–0.85초: 어둡게 처리한 금속 링 위로 빛이 이동합니다.
- 0.85–1.47초: 흰 화면으로 넘어가며 제공된 파란 로고와 회사명이 나타납니다.
- 1.47–1.80초: 오프닝이 사라지고 현재 홈페이지가 드러납니다.
- 다시 재생, 장면별 정지, 타임라인 탐색, 0.5배속 재생, 건너뛰기와 Escape 종료를 제공합니다.
- 동작 줄이기 설정에서는 자동 재생하지 않고, 수동 재생은 로고 정지 화면만 잠깐 표시합니다.
- 이미지를 기다리는 동안 페이지를 가리지 않습니다. 자동 재생용 이미지 준비 제한은 1.5초이고 실패 시 본문을 그대로 표시합니다.
- 정식 적용 전 시안이므로 방문당 1회 제한 없이 시안 페이지 접속 때 재생합니다. 정식 적용 시 세션당 1회 처리를 추가합니다.

## 제작 자산

금속: 내장 imagegen으로 생성한 콘셉트 사진. 실제 삼호 생산품의 사양을 나타내는 이미지가 아닙니다. 생성 도구에는 모델 선택 항목이 없으므로 구체적인 모델 버전은 확인되지 않았습니다. 생성 프롬프트는 `image-prompt.txt`, 원본은 `metal-ring-original.png`입니다.

로고: 사용자 제공 `samho-logo-blue-square-300ppi.png`에서 종횡비를 유지한 480px 웹용 WebP를 생성했습니다. 디자인과 색을 다시 생성하지 않았으며 제공된 PNG와 TIFF 원본은 수정하지 않았습니다.

## 재생성

기본 홈페이지를 빌드한 다음 `python3 scripts/build_opening_preview.py`를 실행합니다. 시안만 수정한 경우에도 해당 스크립트로 HTML/CSS/JS를 갱신합니다. 이 스크립트는 루트 홈페이지를 읽기만 합니다.
