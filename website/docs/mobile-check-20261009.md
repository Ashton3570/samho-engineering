## 점검 환경과 한계

- macOS Codex 내장 브라우저에서 360×844, 390×844, 430×844 모바일 크기와 1440×960 데스크탑 크기를 확인했습니다. 데스크탑 브라우저의 스크롤바를 제외한 실제 콘텐츠 폭은 각각 345, 375, 415, 1425px입니다.
- 이는 화면 크기별 브라우저 점검이며, iPhone/Android 실기기 점검은 아닙니다.
- 제어 가능한 실물 휴대폰 또는 원격 실기기 서비스가 연결되지 않았습니다. 실기기의 FPS, 발열, 배터리 소모, 셀룰러 환경의 LCP/INP 수치는 측정하지 못했습니다.

## 확인 결과

- 세 모바일 크기 모두 문구가 화면 안에 표시되고 가로 페이지 넘침이 없었습니다.
- 이전/다음 사진 버튼은 모두 44×44px 원형이며 다음 사진 조작과 이미지 로딩이 정상입니다.
- 모바일 메뉴의 한글 → EN → 한글 전환과 영문 소개 문구를 확인했습니다.
- 메인 생산 제품 보기 → 제품 목록 이동이 정상입니다.
- 규격 비교 체크박스는 상세 페이지로 이동하지 않고 선택되며, 2개 제품 비교 팝업이 정상입니다.
- 제품 카드의 외경 숫자 부분을 눌러 TRB 상세 페이지로 이동했습니다.
- 모바일 인증서 팝업 이미지가 로딩되며, 닫기만 있고 기존의 확대/원본 열기 도구는 없습니다.
- 점검 중 브라우저 경고·오류 로그는 없었습니다.
- 브라우저가 선택한 모바일 히어로 AVIF 1280px 이미지 용량은 각각 약 76, 60, 56, 23 KiB입니다. 고해상도 화면에서는 더 큰 반응형 이미지가 선택될 수 있습니다.
