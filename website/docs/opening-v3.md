## 로컬 홈페이지 연결 (2026-09-22)

사용자 요청으로 `/` 첫 화면에 4.5초 오프닝을 연결했다. 별도 시안 `/previews/opening-v3/`도 유지한다. 공개 배포는 하지 않았다.

- 2.75초 로고 완성, 이후 한글·영문 상호명, 3.85~4.5초 히어로 전환 유지.
- 홈페이지에서는 시안 조작 도구를 넣지 않고 건너뛰기만 제공한다.
- 홈 진입 및 새로고침에서 재생. 다른 페이지에는 로드하지 않는다.
- 해시로 특정 섹션에 접근하거나 동작 줄이기를 설정한 경우 자동 재생 생략.
- 이미지 다운로드를 기다리지 않는 인라인 SVG. 애니메이션 스크립트가 로드되지 않아도 홈페이지에 접근 가능.
- 재생 종료/건너뛰기/Escape에서 페이지 조작과 스크롤 복원, 본문으로 키보드 포커스 이동.
- `opening_component.py`는 홈에 로고 마크업과 공통 애니메이션을 삽입한다.
- `build_indigo_opening.py`는 홈을 복제하고 시안 도구만 추가하여 로고 중복을 방지한다.
- 브라우저에서 자동 재생 → 4.5초 종료, 시안 도구 미노출, 모바일 건너뛰기 및 가로 넘침 없음 확인.
