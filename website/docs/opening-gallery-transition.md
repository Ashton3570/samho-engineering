# 갤러리 히어로 전환

사용자 요청: 전체 개선점은 보고서로만 정리하고, 오프닝 전환만 수정한 뒤 배포.

- 4.5초 총 길이와 2.75초 로고 형성 완료 시점 유지.
- 흰 레이어가 3.3~4.5초에 걸쳐 천천히 옅어지고 밝은 블루 제품 사진으로 연결.
- 사진은 1.8% 확대 상태에서 원래 크기로 정착. 문구 카드는 3.75~4.5초에 투명도와 12px 이동으로 등장.
- 오프닝 동안 스크롤 잠금으로 생길 수 있는 폭 변화를 막도록 스크롤바 공간 유지.
- 완료 시 전환 변수 제거 및 기존 상호작용 복원.
- 3.5초, 4.1초, 4.5초 장면 비교. 전환 전후 히어로 너비 1425px 동일(1440px 검수 화면).
- 전체 점검 보고서는 프로젝트 상위 output/site-audit에 저장하며 웹 공개 폴더에 포함하지 않음.

## 방문 중 재생 규칙 · 2026-09-23

- 화면의 건너뛰기 버튼 제거. 기존 동작 줄이기 설정과 Escape 키 처리는 유지.
- 탭별 sessionStorage에 오프닝 시청 여부를 기록. 제품·회사소개 페이지에서 홈으로 돌아오거나 뒤로 가기를 해도 반복하지 않음.
- 홈을 새로고침하면 다시 재생. 새 탭의 첫 방문도 재생.
- 첫 화면을 가리는 흰 레이어에도 동일한 조건을 적용하여 홈 재방문 시 번쩍임 방지.
- 오프닝 시안 전용 페이지의 재생·장면 확인 도구는 유지하며 본 사이트 시청 기록에 영향을 주지 않음.
- node scripts/check_opening_session.cjs: 첫 방문, 재방문, 새로고침, 뒤로 가기, 앵커 이동, 동작 줄이기, 저장소 사용 불가 상황 등 9개 검사 통과.
- 브라우저에서 첫 방문, 제품 페이지→홈, 새로고침, 뒤로 가기를 직접 확인. 건너뛰기 버튼 0개, 홈 복귀 시 오프닝 숨김·흰 레이어 없음·본문 상호작용 정상, 콘솔 오류 없음.
