# 흰 배경 로고 오프닝 — 로컬 시안

경로: `/previews/opening-v2/`. 배포 및 원격 푸시 없이 로컬에서만 작업했습니다. 기존 메인 히어로와 이전 오프닝 시안은 수정하지 않았습니다.

## 연출

- 3초 길이. 처음에는 큰 파란 윤곽이 화면을 채우고, 선이 완성되는 동안 중앙으로 천천히 축소됩니다.
- 약 1.04~2.05초에 원본 로고의 파란 면이 아래부터 채워집니다.
- 약 2.1초에 축소가 멈추고 아래에 작은 회사명과 영문이 등장합니다.
- 2.6~3초에는 흰 배경을 유지하며 기존 홈페이지로 부드럽게 넘어갑니다.
- 다시 재생, 장면별 정지, 시간 탐색, 느린 재생, 건너뛰기, Escape 종료를 제공합니다.
- OS 동작 줄이기 설정에서는 자동 재생하지 않고, 수동 재생 시 완성 로고 정지 장면만 표시합니다.

## 원본 보존

사용자가 제공한 `samho-logo-blue-square-300ppi.png`의 파란 픽셀 경계를 분석해 5개 윤곽을 추출했습니다. 해당 벡터는 선 그리기와 영역 마스크에만 사용하며, 완성 장면은 제공된 래스터 원본을 웹용으로 축소·압축한 이미지입니다. 원본 PNG/TIFF를 변경하지 않았습니다. 새 로고 생성 및 유료 영상 생성 도구를 사용하지 않았습니다.

웹용 로고: 960 × 960px WebP, 약 40KB. 원본 구도는 SVG 좌표계로 유지합니다. 큰 시작 크기는 뷰포트에 비례하며, 모바일에서는 일부 윤곽이 화면 밖으로 확장됩니다.

## 빌드

`python3 scripts/build_logo_opening.py`

소스: `src/opening-v2/`. 저장된 윤곽 좌표를 사용하므로 빌드 시 이미지 분석 패키지가 필요하지 않습니다. 전체 사이트 빌드 후에도 위 명령으로 시안의 홈페이지 사본을 갱신할 수 있습니다.
