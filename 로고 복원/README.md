# 삼호 로고 고해상도 복원

사용자가 2026-09-22 제공한 짙은 청색 단색 로고 스크린샷을 기준으로 복원했습니다. 기존 밝은 청색 테두리 로고와는 별도 자산입니다. 사이트 및 오프닝 파일을 교체하거나 외부 배포하지 않았습니다.

최종 파일:
- `samho-logo-indigo-vector.svg`: 해상도에 독립적인 벡터. 투명 배경.
- `samho-logo-indigo-4096-transparent.png`: 4096 × 4096px, 실제 투명 배경, 300ppi 메타데이터.
- `samho-logo-indigo-4096-white.png`: 같은 크기의 흰 배경 PNG.
- `samho-logo-indigo-preview.png`: 빠른 확인용 1200px 흰 배경 PNG.

복원 과정:
1. 내장 imagegen으로 체크무늬 제거와 윤곽 복원을 시도했습니다. 결과는 1254px였고 경계에 잔여 거칠음이 있어 최종 고해상도 자산으로 채택하지 않았습니다. 중간 결과와 프롬프트를 별도로 보존했습니다.
2. 원본의 파란 영역을 측정해 바깥·안쪽 원호, H의 직선과 사각 모서리, 두 원을 벡터 경로로 재구성했습니다. 손실된 가장자리와 흐릿한 경계는 원호·직선으로 정돈했습니다.
3. 첨부 스크린샷 내부 파란 픽셀의 중앙값을 기준으로 단색 #1E2083을 사용했습니다. 이는 첨부 이미지에서 추정한 색이며 별도 CI 지정 색상값은 아닙니다.
4. 벡터를 Core Graphics로 직접 렌더링해 4096px PNG를 생성했습니다. 작은 이미지를 단순 확대하는 방식과 달리 곡선과 직선이 해당 해상도에서 새로 그려집니다.

배경 체크무늬와 화면 테두리는 로고에 포함하지 않았습니다. 원본 스크린샷은 `samho-original-reference.png`로 보존했습니다.

재생성: `python3 build_vector.py` 후 `swift render_vector.swift <이 폴더의 절대경로>`.
