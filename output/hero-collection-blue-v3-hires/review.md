# 고해상도 보정 및 갤러리형 히어로 적용

## 이미지
- 입력: V2, 사용자가 승인한 굴곡 수정본. 기존 V1/V2와 원본 25-02 보존.
- 내장 이미지 생성 도구로 금속 경계와 질감을 보정. 프롬프트는 prompt.txt.
- 도구 요청 크기는 6144×4096, 실제 반환은 1536×1024. 그 보정본을 macOS sips로 4배 확대해 6144×4096 PNG로 출력.
- 픽셀 수 확대는 원본 촬영 디테일 복원을 뜻하지 않는다. 보정 과정에서 반사와 질감에 미세한 변화가 있다.
- 시각 검수: ① 이전에 수정한 왼쪽 금속 면의 곧은 옆선 유지 ② 위아래 연결부 및 구멍 확인 ③ 주변 링/앞쪽 케이지/작은 링 구성 확인 ④ 전체 구도와 블루 배경 확인.

## 적용
- 선택한 02 제품 갤러리형을 로컬 홈페이지에 적용: 흰색 헤더, 전체 너비 사진, 왼쪽 아래 흰색 설명 카드.
- 기존 홈페이지 본문 및 4.5초 오프닝 유지. 공개 배포 없음.
- WebP 768~3840px, 약 90~622KB. 원본 PNG는 히어로에서 다운로드하지 않음.
- 1440×900 및 390×844 브라우저 검사: 수평 넘침 없음, 사진 정상 로딩, 카드와 버튼 배치 확인.
- 모바일 메뉴 열기/닫기 확인, 브라우저 오류 없음. 오프닝 완료 뒤 갤러리형 히어로 표시 확인.
